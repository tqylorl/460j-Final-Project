# Calorie Estimator

Basic, command-line interface which takes a picture of food and its
weight, and returns an estimation for calories

## Installation

Get dependencies:
```
pip install -r requirements.txt
```

If you want to use the model I have already trained, all you need to
do is:
```
python calorie_estimator.py
```

To train a new model yourself:
```
python train_food_classifier.py
```
